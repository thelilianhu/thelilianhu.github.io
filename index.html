🔁TASK FRAMEWORK
智能体任务执行框架Agent Task-Execution Framework
2026
任务状态机与介入成本 · 方案负责人Task state machine & interruption cost · Author
  • 先做一手拆解：Claude Code CLI 的官方状态色表与 AskUserQuestion 介入规范、OpenAI Codex Micro 的六色状态机、Android Halo 的系统级状态层、豆包手机的 GUI Agent 与虚拟屏执行Started with first-hand teardowns: Claude Code CLI's documented state colors and AskUserQuestion contract, OpenAI Codex Micro's six-color state machine, Android Halo's OS-level status layer, and Doubao Phone's GUI agent on a shadow display
  • 结论：业界正收敛到同一个最小状态集，且只把颜色留给「需要你」和「出结果」两个时刻。这成为下面两项设计的依据Finding: the industry is converging on one minimal state set, and reserves color for only two moments, "needs you" and "done." That became the basis for the two designs below.
  • 五态任务状态机（Idle / Thinking / Needs Input / Error / Complete），把任务生命周期从对话轮次中解耦：用户一追问，后台任务不再被静默终止A five-state task machine (Idle / Thinking / Needs Input / Error / Complete) that decouples task lifecycle from conversation turns: a follow-up question no longer silently kills the background job
  • human-in-the-loop 三级介入成本模型：待选择 1 秒级 / 待澄清 10 秒级 / 待操作应用 分钟级；原则是能 A 不 B、能 B 不 CA three-tier human-in-the-loop cost model: pick-one at seconds, clarify at tens of seconds, hand-off-to-an-app at minutes. The rule: prefer A over B, B over C.
  • 按交付形态而非时长划分四类任务；同期拆解 DeepSeek Harness (dsh) 的 host plane 与 agent preset 平面划分，及其与「统一大脑 + 按需挂载技能」的同构关系Classified tasks by delivery shape rather than duration; also read DeepSeek Harness (dsh) at source level, on how it splits the host plane from per-session agent presets and how that maps onto a shared-brain-plus-mounted-skills design

应用内分屏 · 交互创新In-app split screen · Interaction Innovation
  • 业界首发的应用内分屏方案「平行视界」，成为 Mate X 卖点特性，功能开启率 98%+Industry-first in-app split screen — a Mate X selling point with 98%+ adoption
  • 机制上以 Activity 为单位做系统侧分屏：应用只需增加一个 easygo.json 声明哪些页面对可以并排，不改业务代码，适配成本压到接近为零，这是生态能起量的前提Mechanically, the split happens system-side at the Activity level: an app only declares which page pairs may sit side by side in an easygo.json file, with no changes to its own business code. Driving adaptation cost to near zero is what let the ecosystem scale.
  • 留了两档模式：通用导航模式下右侧始终承接最新页面，自定义模式由应用自己声明页面对，把控制权交回给更懂自己业务的一方Two modes by design: in navigation mode the right pane always takes the newest page; in custom mode the app declares its own page pairs — handing control back to whoever understands the product best.
  • 与腾讯、淘宝等头部应用共建生态，首批 80+ 应用适配，输出开发者指导文档与白皮书Co-built the ecosystem with Tencent, Taobao and more — 80+ launch apps, plus the developer guide & white paper
