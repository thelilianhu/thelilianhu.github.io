# 个人作品集 · 部署说明

这个文件夹可以直接变成一个公开网址，全程约 10 分钟，不需要写代码。

## 步骤

1. 打开 https://github.com/new 新建一个 **public** 仓库，名字建议 `lillianhu` 或 `portfolio`
2. 在仓库页面点 **Add file → Upload files**，把本文件夹里的 `index.html` 和 `resume.pdf` 拖进去，Commit
3. 进 **Settings → Pages**，Source 选 `Deploy from a branch`，Branch 选 `main` / `(root)`，Save
4. 等 1–2 分钟，页面顶部会出现网址：`https://<你的用户名>.github.io/<仓库名>/`

## 检查（必须做）

- [ ] 用**无痕窗口**打开那个网址 —— 确认未登录也能看到
- [ ] 点页面上的「简历 PDF」按钮，确认 PDF 能打开
- [ ] 用手机打开一遍 —— Tianyi 很可能在手机上看

## 顺带的好处

这个仓库本身就是一个公开的 GitHub 痕迹。加上后面要发的 dsh 插件仓库，
你的 GitHub 从「空的」变成「有两个东西」，而这正是简历上「开源」那一节最缺的。

## 之后要更新时

改完 `index.html` 重新上传覆盖即可，网址不变。
